# 🐍 Python OOP Assignment  

This project contains examples of **Object-Oriented Programming (OOP)** concepts in Python, including **classes, constructors, methods, inheritance, and polymorphism**.  

---

## 📌 Features  

### 1. Smartphone Class 🏗️  
- Represents a smartphone with attributes (`brand`, `model`, `storage`).  
- Methods to:  
  - Power on/off  
  - Check storage  
- Demonstrates **constructors, attributes, and methods**.  

### 2. Polymorphism Challenge 🎭  
- Base class: `Animal` with a method `move()`.  
- Subclasses:  
  - `Dog` → runs 🐕  
  - `Fish` → swims 🐟  
  - `Bird` → flies 🐦  
- Demonstrates **polymorphism** (same method name, different behavior).
